## 核心摘要

客户希望在 Windows 电脑上完成中文会议实时转写、多人区分和本地报告检索，重点关注律师谈话内容是否会被第三方长期保存。客户倾向先用 5 个账号试用两周，但尚未确认采购、预算和开始时间。私有化部署被提出，但双方没有确认其必要性或成本。下一步是供应方提供数据流说明和试用方案，客户完成内部合规确认。

## 议题与讨论

### 1. 使用场景

- 陈玥表示主要场景是案件讨论、客户访谈和内部周会，单场时长通常为 40–90 分钟。
- 客户希望会议结束后 3 分钟内得到结构化纪要，并能人工修改。
- 罗宁提出需要按照案件编号检索历史会议，但案件编号如何录入尚未讨论清楚。
- 手机端被提及，但客户当前优先级仍是 Windows。

### 2. 隐私与数据流

- 张骁说明当前版本会将音频发送给腾讯 ASR，将转写文本发送给 DeepSeek 生成摘要；报告文件保存在本机。
- 罗宁询问第三方服务的日志保留周期。会议中没有提供经过核实的具体天数。
- 陈玥表示，如果音频或文本会被用于模型训练，需要额外的客户授权。
- 私有化部署作为可能方案被提出，但未确认技术范围、服务器要求和报价。

### 3. 试用范围

- 陈玥倾向先安排 5 个账号试用两周，覆盖行政、律师和信息化人员。
- 罗宁要求试用前提供网络域名清单、数据流向图和卸载说明。
- 张骁表示可以准备试用方案，但没有承诺具体交付日期。
- 客户尚未确定试用开始时间，需要等待合规负责人意见。

### 4. 采购与预算

- 客户未披露预算。
- 陈玥表示如果试用有效，会进入采购评估；这不构成采购承诺。
- 双方没有讨论合同期限、账号单价或付款方式。

## 已确认决策

1. 下一阶段只评估 Windows 版本，手机端不作为本次试用前置条件。
2. 在启动试用前，供应方需要提供数据流说明、网络域名清单和卸载说明。
3. 客户需要先完成内部合规确认。
