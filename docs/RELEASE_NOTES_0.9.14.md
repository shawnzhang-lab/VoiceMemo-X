# VoiceMemo X / 速说速记X 0.9.14

这是一次界面语言切换热修复，解决切换中英文客户端后，输出语言下拉框变灰并被锁定的问题。

## 修复内容

- 切换中文或英文界面后，输出语言仍可正常选择；
- 界面语言切换不会改变已经选择的输出语言；
- 日常语音翻译与实时会议纪要继续并行工作，不再受旧版会议模式互斥逻辑影响；
- 新增旧会议设置存在时的中英文往返切换回归测试。

## 下载

下载 `VoiceMemo-X-0.9.14-win-x64-lite.zip` 及同名 `.sha256` 文件，核对 SHA-256 后解压，运行 `速说速记X.exe`。详细步骤见 [下载与安装指南](DOWNLOAD_GUIDE.zh-CN.md)。

Lite 包不含本地 ONNX 模型权重。日常云端语音输入、翻译和会议报告仍可使用；本地语义向量检索与本地说话人数预判会降级。

## 使用提醒

- 输出语言翻译依赖用户自己的 DeepSeek API Key；
- 第三方 API 可能收费，且需要可用余额与网络连接；
- 当前 Windows 可执行文件尚未代码签名，首次启动可能出现 SmartScreen 提示；
- 源代码使用 Apache-2.0，小夜角色和 UI 美术使用独立非商业素材许可。
