# VoiceMemo X / 速说速记X 0.9.10

首个公开源码版本。VoiceMemo X 是一个独立开发的 Windows 语音输入与实时会议纪要 Demo，与飞书、腾讯云或 DeepSeek 均无隶属或授权关系。

## 主要功能

- 右 Alt：全局日常语音转文字，支持中文、英语、粤语、日语、韩语等识别模式；
- 可选 DeepSeek 文本整理、智能分点和多语言输出；
- 左 Alt：同时记录麦克风与电脑播放声，生成本机 Markdown 会议报告；
- 中英文客户端、悬浮窗、会议模板与纠错词典；
- 报告历史、处理进度、复制、导出与回收站删除。

## 下载

下载 `VoiceMemo-X-0.9.10-win-x64-lite.zip` 及同名 `.sha256`，校验后解压，运行 `速说速记X.exe`。详细步骤见 [下载与安装指南](DOWNLOAD_GUIDE.zh-CN.md)。

Lite 包不含本地 ONNX 模型权重。日常云端语音输入、翻译和会议报告仍可使用；本地语义向量检索与本地说话人数预判会降级。

## 使用前必须知道

- 本项目采用 BYOK：需要用户自行配置腾讯云 ASR 和可选的 DeepSeek API Key；第三方服务可能收费，本项目不会提供免费云额度；
- 腾讯 Speaker 2.0 可能与普通实时 ASR 分开计费，请以腾讯云控制台为准；
- 会议录音前应取得参与者同意；AI 生成的报告、数字、决定和行动项必须人工复核；
- 当前 Windows 可执行文件尚未代码签名，首次运行可能出现 SmartScreen 提示；
- 源代码采用 Apache-2.0；“小夜”角色与 UI 美术采用独立的非商业许可证，商业发行必须替换相关素材；
- 当前仍是实验性 Demo，不承诺生产级稳定性、准确率或服务可用性。

## 0.9.10 修复
