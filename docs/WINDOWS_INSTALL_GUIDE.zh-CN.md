# Windows 安装教程

## 1. 解压

1. 先按[下载教程](DOWNLOAD_GUIDE.zh-CN.md)核对 SHA-256。
2. 右键 ZIP，选择“全部解压”。
3. 建议解压到当前用户可写目录，例如：

   ```text
   %USERPROFILE%\Apps\VoiceMemo-X\
   ```

4. 不要直接在 ZIP 预览窗口里运行程序，也不要安装到需要管理员权限的系统目录。

## 2. 第一次启动

双击 `速说速记X.exe`。当前程序尚未代码签名，Windows SmartScreen 可能提示“Windows 已保护你的电脑”。只有在文件来自项目官方 Release 且 SHA-256 完全一致时，才可以选择“更多信息”后继续运行。

程序打开后：

1. 允许麦克风权限。
2. 打开“连接设置”。
3. 填写腾讯云 AppID、SecretID、SecretKey。
4. 如需智能结构化、翻译或会议报告，再填写 DeepSeek API Key。
5. 保存设置。

API 的注册和开通步骤见 [API 配置索引](API_SETUP_INDEX.zh-CN.md)。

## 3. 功能验证

### 日常语音转文字

1. 打开记事本或浏览器输入框，并把光标点进去。
2. 按一次**右 Alt**。
3. 悬浮窗显示“请输入语音”后说一句短句。
4. 再按一次**右 Alt**结束。
5. 文字应回到刚才的输入框；自动输入失败时会保留在剪贴板。

### 实时会议纪要

1. 建议佩戴耳机，避免电脑扬声器声音再次进入麦克风形成回声。
2. 按一次**左 Alt**开始。
3. 播放一段会议声音并进行简短发言。
4. 再按一次**左 Alt**结束。
5. 在“会议报告”页查看处理进度和最终报告。

## 4. 开机自启

主页打开“开机自启”后，程序会在当前 Windows 用户登录时启动。若不再需要，可在主页关闭；不必手动修改注册表。

## 5. 常见安装问题

- **双击没有反应**：确认系统是 Windows 10/11 x64，并查看任务管理器是否已有进程。
- **右 Alt/左 Alt 无反应**：退出重复运行的旧进程，再重开；部分键盘布局会把右 Alt 当作 AltGr。
- **只能复制，不能自动输入**：目标软件如果以管理员身份运行，速说速记X也需要相同权限；更推荐让双方都以普通权限运行。
- **会议没有远端声音**：确认远端声音从 Windows 当前默认播放设备输出。
- **提示欠费或未授权**：分别检查腾讯云服务开通、资源包/后付费和 API 密钥权限。

更多错误处理见 [TROUBLESHOOTING.zh-CN.md](TROUBLESHOOTING.zh-CN.md)。

## 6. 卸载

先退出程序，再删除解压目录。个人配置、记忆和会议报告仍保存在：

```text
%LOCALAPPDATA%\VoiceMemoryDemo
```

确认不再需要后，才手动删除该目录。删除前请先导出需要保留的会议报告。
