# VoiceMemo X / 速说速记X 0.9.13

这是一次语言选择器实时刷新热修复，解决“菜单已经选中新语言，但输入栏或输出栏仍显示旧文字”的问题。

## 修复内容

- 输入语言和输出语言在运行中切换后，关闭菜单即可立即显示当前选择；
- 已选文字不再经过容易缓存旧值的嵌套模板；
- 后台保存值、悬浮窗输出语言状态和主页可见文字保持一致；
- 新增输入语言自动、中文、英文往返切换和输出语言中英文往返切换回归测试。

## 下载

下载 `VoiceMemo-X-0.9.13-win-x64-lite.zip` 及同名 `.sha256` 文件，核对 SHA-256 后解压，运行 `速说速记X.exe`。详细步骤见 [下载与安装指南](DOWNLOAD_GUIDE.zh-CN.md)。

Lite 包不含本地 ONNX 模型权重。日常云端语音输入、翻译和会议报告仍可使用；本地语义向量检索与本地说话人数预判会降级。

## 使用提醒

- 输出语言翻译依赖用户自己的 DeepSeek API Key；
- 第三方 API 可能收费，且需要可用余额与网络连接；
- 当前 Windows 可执行文件尚未代码签名，首次启动可能出现 SmartScreen 提示；
- 源代码使用 Apache-2.0，小夜角色和 UI 美术使用独立非商业素材许可。
