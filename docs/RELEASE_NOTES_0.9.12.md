# VoiceMemo X / 速说速记X 0.9.12

这是一次语言下拉显示热修复，解决“内部已经选择中文，但输入栏仍显示旧的英语”的问题。

## 修复内容

- 输出语言选中栏现在直接跟随当前选项，不再保留旧文字；
- 中文、英文和其他输出语言在关闭下拉框后都会显示真实选择；
- 新增中文与英文往返切换的可见文字回归测试；
- 0.9.11 已有的自动启用翻译、悬浮窗输出语言提示和失败保护继续保留。

## 下载

下载 `VoiceMemo-X-0.9.12-win-x64-lite.zip` 及同名 `.sha256` 文件，核对 SHA-256 后解压，运行 `速说速记X.exe`。详细步骤见 [下载与安装指南](DOWNLOAD_GUIDE.zh-CN.md)。

Lite 包不含本地 ONNX 模型权重。日常云端语音输入、翻译和会议报告仍可使用；本地语义向量检索与本地说话人数预判会降级。

## 使用提醒

- 输出语言翻译依赖用户自己的 DeepSeek API Key；
- 第三方 API 可能收费，且需要可用余额与网络连接；
- 当前 Windows 可执行文件尚未代码签名，首次启动可能出现 SmartScreen 提示；
- 源代码使用 Apache-2.0，小夜角色和 UI 美术使用独立非商业素材许可。
