# VoiceMemo X / 速说速记X 0.9.11

这是一次目标语言状态修复版，重点解决“界面选择 English，但实际仍输出中文”的问题。

## 修复内容

- 选择任一输出语言时自动开启语言转换，重新选择当前选项也会生效；
- 右 Alt 日常输入悬浮窗显示真实输出状态，例如“输出为英文”“输出为中文”或“保持原文”；
- DeepSeek 翻译失败时不再把中文原文静默当作英文结果回填，而是明确提示失败并记录本地诊断信息；
- 中文、英文界面的语言下拉、悬浮窗和中文转英文链路均已重新测试。

## 下载

下载 `VoiceMemo-X-0.9.11-win-x64-lite.zip` 及同名 `.sha256` 文件，核对 SHA-256 后解压，运行 `速说速记X.exe`。详细步骤见 [下载与安装指南](DOWNLOAD_GUIDE.zh-CN.md)。

Lite 包不含本地 ONNX 模型权重。日常云端语音输入、翻译和会议报告仍可使用；本地语义向量检索与本地说话人数预判会降级。

## 使用提醒

- 输出语言翻译依赖用户自己的 DeepSeek API Key；
- 第三方 API 可能收费，且需要可用余额与网络连接；
- 当前 Windows 可执行文件尚未代码签名，首次启动可能出现 SmartScreen 提示；
- 源代码使用 Apache-2.0，小夜角色和 UI 美术使用独立非商业素材许可。
