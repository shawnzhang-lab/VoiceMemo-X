# 腾讯 Speaker 2.0 注册与配置

这部分负责左 Alt 实时会议纪要和导入会议音视频时的多人转写。

## 1. 它与普通 ASR 的关系

Speaker 2.0 仍属于腾讯云语音识别，但使用大模型 2.0 引擎：

```text
16k_zh_en_speaker_2.0
```

它与普通实时 ASR 使用同一组腾讯云 AppID、SecretID、SecretKey，不需要再创建第二套密钥；但大模型 2.0 的用量和普通 ASR 免费额度/资源包不是一回事，需要单独确认计费和开通状态。

## 2. 开通

1. 登录[语音识别控制台](https://console.cloud.tencent.com/asr)。
2. 确认账号已开通实时语音识别和大模型 2.0 对应能力。
3. 打开[语音识别设置](https://console.cloud.tencent.com/asr/settings)，检查中国大陆流量或跨境流量的后付费状态。
4. 打开[资源包页面](https://cloud.tencent.com/document/product/1093/54408)核对是否存在适合当前用量的套餐；若只是短期测试，优先确认后付费是否更合适。

截至 2026-08-21，腾讯官方计费文档将实时语音识别大模型 2.0列为按时长计费能力，且没有普通实时 ASR 的每月免费额度。价格和活动会变化，以控制台下单页为准。

## 3. 客户端配置

客户端没有单独的 Speaker 2.0 开关：

- 按左 Alt 进入实时会议时，自动使用 Speaker 2.0；
- 导入会议音视频时，自动使用 Speaker 2.0；
- 右 Alt 日常语音输入继续使用普通 ASR。

只需在“连接设置”保存腾讯云凭证。不要把普通识别引擎手工改成 Speaker 2.0；会议代码会按场景选择。

## 4. 最小测试

1. 准备一段 1–2 分钟、至少两个人轮流说话的公开视频或非敏感录音。
2. 用左 Alt 实时录制，或在“会议报告”页导入文件。
3. 等待报告生成。
4. 检查原始转写是否出现 `Speaker 1`、`Speaker 2` 等匿名标签。
5. 在腾讯控制台核对本次大模型 2.0 用量。

说话人编号只是本次音频内的聚类标签，不等于姓名识别；重叠说话、极短插话、相似声线和噪声都可能导致分离错误。
