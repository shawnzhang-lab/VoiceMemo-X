## GitHub 首页短版

速说速记X（VoiceMemo X）是一款 Windows BYOK 语音效率工具。按右 Alt 可在聊天、网页、文档和搜索框中完成语音输入；按左 Alt 可同时采集麦克风与电脑播放声音，生成带匿名说话人标签的会议报告。它还支持本地纠错词典、智能分点、翻译、可编辑总结模板、中英文界面，以及报告复制、导出和删除。

项目当前是可运行的实验性 Demo。腾讯云 ASR 与 DeepSeek 费用由用户自己的账户承担，会议报告中的关键事实、决定和行动项仍需人工复核。

## 产品页完整版

### 说完，就能继续工作

很多语音工具只能把录音变成一大段文字，接下来仍要手动整理、复制和寻找输入位置。速说速记X 把这条流程缩短成两个热键：

- **右 Alt：日常语音输入。** 把光标放在聊天、浏览器、文档或搜索框，按一次开始说话，再按一次结束。文字会经过本地专有词纠错，并可选择去除口头禅、修正措辞、智能分点或翻译后，回到原输入框。
- **左 Alt：实时会议纪要。** 同时采集默认麦克风和当前电脑播放的会议声音，生成匿名说话人分段、核心摘要、讨论主题、项目约束、决定、行动项和待确认问题。处理进度与历史报告都可以在客户端查看，并支持复制、导出和删除。

### 越用越贴近你的表达

产品提供本地纠错词典和 SQLite 本地记忆。你可以把经常听错的人名、产品名和术语保存为固定写法；启用 AI 整理时，客户端只取少量相关本地记忆作为上下文，帮助模型保持用词和表达习惯。

这里的“记忆”不是无限记录你的一切，也不是保证模型永远理解当前联系人或会话。当前版本主要依据目标应用、词典和语义相关片段提供辅助，重要内容仍应由用户确认。

### 默认把边界说清楚

速说速记X 是 BYOK 桌面 Demo，不是腾讯云、DeepSeek、飞书或 OpenAI 的官方产品。音频会发送至腾讯云 ASR；启用 AI 整理、翻译或会议总结时，转写文字及少量命中记忆会发送给 DeepSeek。密钥使用 Windows DPAPI 保存在当前用户下，历史与报告默认保存在本机。

录制会议前应取得参与者同意。Speaker 2.0 产生的是匿名说话人标签，并会产生独立用量。AI 报告可能漏记、误解或生成不准确内容，关键数字、决定、负责人和截止日期必须回听或人工核对。

## 功能卡片文案

### 全局语音输入

在任意常见输入框按右 Alt 开始说话，再按一次结束。无需手动复制粘贴；自动注入失败时会安全回退到剪贴板。

### 5 秒防误触

启动后 5 秒内没有检测到有效语音，客户端会自动关闭，避免误触产生不必要的云端调用。

### 智能结构化

可选去除语气词、修正明显错词和标点，并把连续口述整理成有逻辑的 1、2、3 分点。它会增加一次模型处理时间，因此适合长指令，不一定适合每个短词。

### 翻译输入

自动识别普通话、英语和粤语，并可把中文口述整理为英语、日语等目标语言后输入到当前文本框。

### 实时会议报告

按左 Alt 同时记录本机麦克风和电脑播放声音。结束后在客户端查看处理进度、历史概览和完整 Markdown 报告。

### 匿名说话人分段

导入会议音视频和当前实时会议流程使用腾讯 Speaker 2.0，对不同声音生成匿名 Speaker 标签。它不确认真实姓名，也不应作为身份认证。

### 本地纠错词典

把容易听错的产品名、人名和术语保存为“识别写法 → 正确写法”，支持查看、新增、编辑和删除。

### 可编辑总结模板

决定会议报告的章节、顺序和关注重点。事实核验、数字检查和禁止虚构行动项等安全约束不会因为模板修改而关闭。

### 中英文界面

客户端、设置窗口和悬浮提示支持中文与英文切换，便于中文和英文用户理解当前状态与热键。

## 视频/社交平台简介草稿

### 中文版

这期演示一个正在开发中的 Windows 开源语音工具——速说速记X。

它把两个高频场景分别放在左右 Alt：右 Alt 用于日常语音输入，可以纠错、分点和翻译后直接回到当前输入框；左 Alt 用于实时会议纪要，同时记录麦克风和电脑播放声音，并生成可复制、导出和删除的会议报告。

项目采用 BYOK 模式，需要用户自行配置腾讯云 ASR 和 DeepSeek API。当前仍是实验性 Demo，Speaker 2.0、AI 总结和文本注入都有明确限制，视频会同时展示正常流程和失败回退，而不是只剪成功片段。

项目地址：https://github.com/shawnzhang-lab/VoiceMemo-X

### English version

VoiceMemo X is an experimental BYOK Windows app for global voice dictation and live meeting notes. Press Right Alt to dictate into common text fields, or Left Alt to capture both your microphone and computer audio and generate a structured meeting report. It also includes a local correction dictionary, optional translation and smart formatting, editable report templates, bilingual UI, and local report history.

Cloud transcription and AI features use your own Tencent Cloud and DeepSeek credentials. Speaker labels are anonymous, AI-generated reports require human review, and the current release should be treated as a working demo rather than a production service.

Project: https://github.com/shawnzhang-lab/VoiceMemo-X
