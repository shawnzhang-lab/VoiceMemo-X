# 速说速记X Android Demo

这是 Windows 版“速说速记X”的安卓验证版本，最低支持 Android 8（API 26）。

## 当前能力

- 应用内按钮开始/结束语音输入。
- 可添加到通知栏快捷开关，从其他应用中启动或结束。
- 开始后先在手机本地检测语音；5 秒内无人声自动关闭，不连接腾讯 ASR。
- 检测到语音后连接腾讯实时 ASR，并补发内存中约 1 秒的开头音频。
- 可选 DeepSeek 文本整理与中文翻译。
- 保存最近 20 条成文作为轻量本地表达记忆。
- 完成后自动复制文字，回到目标输入框粘贴即可。
- API 密钥使用 Android Keystore 加密后保存在手机本地。

## 首次安装

1. 安装 APK；如果系统提示，请允许“安装未知应用”。
2. 打开应用，填写腾讯 AppID、SecretID、SecretKey；需要 AI 整理时再填写 DeepSeek API Key。
3. 保存设置并授权麦克风、通知权限。
4. 点击“添加到通知栏快捷开关”。旧版 Android 需要手动编辑通知栏，把“速说速记X”拖进去。
5. 点击开始后在 5 秒内说话，再次点击结束。完成文字会自动复制。

## 构建

先安装 JDK 17，并把 `JAVA_HOME` 指向 JDK 根目录。构建脚本不会从不固定的 `latest` 地址自动下载 JDK；Android 命令行工具和 Gradle 下载包会执行固定 SHA-256 校验。

在项目根目录执行：

```powershell
.\build-android-demo.ps1
```

发布文件输出到：`publish\android\速说速记X-android-demo.apk`。

## Demo 限制

- Android 没有跨品牌统一的“背面双击”API，首版使用通知栏快捷开关。
- 完成后不会越权控制其他应用；首版通过剪贴板回填。
- 手机厂商的省电策略可能限制后台行为，测试时请允许应用后台运行。
- 这是个人测试包，不应把主账号永久密钥打包后公开分发。
